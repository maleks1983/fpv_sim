# FCAT2 UART Telemetry Viewer

Windows-застосунок для приймання та відображення повідомлень, які плата FCAT2 передає через UART. Новий пакет одразу замінює попередній текст у центральній частині вікна; останні 100 значень залишаються в журналі.

## Параметри плати

- Інтерфейс: `USART2`, TX плати — `PA14`
- Швидкість: `115200`
- Формат порту: `8 data bits, no parity, 1 stop bit` (`8N1`)
- Протокол: MSPv2, напрямок `$X<`, команда `0x3007`
- Корисне навантаження: тип тексту, довжина та 16 ASCII-символів
- Контрольна сума: CRC-8/DVB-S2, поліном `0xD5`

## Підключення

1. З'єднайте `PA14 (USART2 TX)` плати з `RX` USB–UART адаптера.
2. З'єднайте землі плати й адаптера. Рівні сигналів мають бути сумісними з 3,3 В.
3. Запустіть застосунок, виберіть COM-порт і `115200`, потім натисніть **Підключити**.

Для перевірки інтерфейсу без плати ввімкніть **Імітація без плати**. Повідомлення змінюватимуть одне одного автоматично.

## Збірка і запуск

```powershell
dotnet build
dotnet run
```

Вихідний протокол звірено з `D:\fcat2\c011_fcat2_test\multitool\osd.cpp` та налаштуваннями `config.h`.
